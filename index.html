ENGLISH

Argos — a local HTML organizer

Argos (阿戈斯) is a lightweight local HTML organizer for macOS 13 or later. It helps you browse, search, categorize and recover HTML output created with agents such as Codex, Claude Code and WorkBuddy. You can also manage data through its CLI. No Argos account is required.

Download the standalone edition, read the support guide, or review the privacy policy. The standalone edition sends anonymous analytics by default and has no analytics off switch; the App Store edition does not include this analytics SDK.
