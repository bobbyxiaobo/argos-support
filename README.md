# 阿戈斯 · 支持与隐私

阿戈斯（Argos）macOS 应用的公开支持与隐私说明网站。

本目录仅包含可公开的静态网页与品牌图片，不包含应用源代码、安装包、用户文档或凭据。

- `index.html`：网站首页
- `support.html`：使用支持（中英文）
- `privacy.html`：隐私政策（中英文）
- `style.css`、`assets/`：样式与品牌图片
- `.nojekyll`：直接发布静态文件

公开联系邮箱：bobbyye2026@qq.com

## 发布

使用独立的公开 GitHub 仓库。在仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，目录 `/ (root)`。

计划发布到 `bobbyye19890223-bit/argos-support`。页面分享图片采用该仓库的预期 Pages 地址；若实际仓库名称不同，请同步修改三个页面的 `og:image` 和 `twitter:image`。预期地址不代表已上线。

发布完成后，验证支持和隐私页面无需登录即可打开，再将对应网址填入 App Store Connect 的 Support URL 与 Privacy Policy URL。

## 维护

应用的统计、联网、权限、账户或文件处理行为变化时，同步更新中英文政策、生效日期及应用内说明。网站内容不应替代对实际上架版本行为和商店隐私申报的核对。
