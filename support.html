快速开始

  1. 连接文档库。在阿戈斯中添加或连接文档库，通过系统文件夹选择窗口，选中存放 HTML / HTM 文件的文件夹并授权访问。可以连接多个文件夹。
  2. 浏览与整理。等待扫描完成后，浏览封面、搜索文档或调整分类。仅连接文件夹不会复制或移动原始文件。
  3. 打开文档。选择文档并打开，系统会交给关联的应用处理；通常是浏览器，也可能是你设置的编辑器。
  4. 按需导入。自动发现只检查你授权的范围。检查待导入清单和目标文档库，确认后，所选文件会被复制到目标位置。

常见问题

为什么没有找到我的文档？

请确认已经连接正确的文件夹，且文件扩展名为 .html 或 .htm。如果文件位于 iCloud 或其他同步文件夹，请先确保它已下载到 Mac。再尝试刷新扫描；权限失效时，重新选择文件夹授权。

自动发现中的部分测试、草稿或旧版本文件可能默认未勾选，请查看完整清单。应用不会自动获得整台电脑的访问权限。

“移除文档”会删除原文件吗？

不会。“从阿戈斯移除”只把文档从文档库的展示与索引中排除；断开文档库也不会删除原始 HTML 文件。应用可能在文档库的 .argos/library.json 中保存分类和排除记录。

为什么封面与浏览器里的页面不完全一样？

封面预览禁用 JavaScript，并阻止 HTTP / HTTPS 远程资源加载，因此依赖脚本或在线图片的页面可能显示不完整。这不会修改你的原文件。需要完整阅读时，请在信任文件来源的前提下打开原文档。

怎样分享给别人？

可以复制文件或使用系统分享菜单。“发送到微信”会复制文件并尝试打开微信，需要你在聊天中自行粘贴、确认发送。如果 HTML 引用了单独的图片、样式或其他文件，请一并提供依赖资源，并保持原有相对路径结构。

可以离线使用吗？

本地文档库的扫描、搜索和整理可离线使用。启用可选使用统计，或通过浏览器、分享应用、同步服务使用在线功能时，相关功能会涉及网络连接。

怎样关闭使用统计？

打开菜单栏 阿戈斯 → 设置 → 隐私，关闭“发送匿名使用数据”。此项默认关闭，不影响本地文档管理功能。详情见隐私政策。

需要注册或删除账户吗？

阿戈斯不提供应用账户注册或登录，因此没有阿戈斯账户需要删除。如需处理本地缓存、文档库配置或隐私请求，请通过邮箱联系我们。

反馈问题时，请附上这些信息

  • 阿戈斯版本、macOS 版本，以及 Mac 使用 Apple 芯片还是 Intel 处理器。
  • 操作步骤、原本期待的结果、实际发生的情况。
  • 如有必要，提供已遮盖私人信息的截图，或不含敏感内容的最小示例。

无需发送密码、验证码、API 密钥或完整私人文档库。文件名、路径和页面内容也可能包含私人信息，请在发送前检查并脱敏。

ENGLISH

Support for Argos

Argos (阿戈斯) organizes local HTML documents on macOS 13 or later. Contact the developer at bobbyye2026@qq.com for help, feedback or privacy questions.

Getting started

  1. Connect a library by choosing a folder containing HTML / HTM files in the system folder picker. You can connect more than one folder.
  2. Let the scan finish, then browse, search or categorize your documents. Connecting a folder does not copy or move its files.
  3. Open a document with its associated application, usually your browser. Automatic discovery only searches locations you authorize; confirmed imports copy selected files to your chosen destination.

Missing files or access errors

Check the selected folder and file extensions. Download cloud-only files to your Mac, refresh the library, or reselect the folder to restore access. Some test, draft or older-version files may be unchecked in the discovery results.

Removal, previews and sharing

Removing a document from Argos or disconnecting a library does not delete the original HTML files. Classification and exclusion settings may be stored in .argos/library.json inside the library folder.

Cover previews disable JavaScript and remote HTTP / HTTPS resources. Script-dependent pages or online images may not appear fully; the original file is unchanged. Only open files from sources you trust.

Sharing uses the clipboard or system share menu. The WeChat option copies the file and opens WeChat when available; you choose the recipient and send it yourself. Include any linked images and stylesheets with their relative folder structure.

Offline use and privacy

Local library functions work offline. Optional analytics, external browsers, sharing apps and cloud storage may use the network. Usage analytics are off by default. In the Chinese interface, turn them off under 阿戈斯 → 设置 → 隐私 → 发送匿名使用数据. Argos has no app account to register or delete. See the privacy policy.

Reporting a problem

Include your Argos and macOS versions, Mac processor type, reproduction steps and expected versus actual behavior. Redact personal information from screenshots or examples. Do not send passwords, verification codes, API keys or a complete private document library.
