隐私政策

说明阿戈斯如何处理信息，以及你可以做出的选择。

生效日期：2026 年 9 月 5 日 · 适用于阿戈斯 macOS 独立安装版、App Store 版及本支持网站

阿戈斯以本地文档管理为核心，无需账户。独立安装版会默认发送匿名使用统计，且不提供关闭开关；App Store 版不包含统计 SDK，也不发送这些统计。统计不包含 HTML 内容、文件名、文件夹名称、完整路径、搜索词或自由输入文本。

本地文件发行渠道与统计你的选择网站与联系English policy

1. 谁负责本应用

本政策由阿戈斯开发者发布，GitHub 账号为 bobbyye19890223-bit。如对数据处理有疑问，或希望提出隐私请求，请联系 bobbyye2026@qq.com。

2. 文档与文件夹权限

你在应用中选择或添加文档库后，阿戈斯会在本机读取其中的 HTML / HTM 文件，提取标题、摘要和文件元数据，并建立索引、分类及封面缓存，以提供浏览、搜索和整理功能。App Store 版受 App Sandbox 限制，使用系统授权与安全作用域书签保存文件夹访问权限。独立安装版不启用 App Sandbox，因此不需要同一套沙盒授权流程；应用设计上只扫描你明确添加的文档库，但 macOS 不会再用 App Sandbox 技术限制其文件访问范围。偏好设置、索引、缓存和相关路径记录保存在本机。

阿戈斯不会将文档内容或文档库上传到开发者服务器。连接文档库不会复制或移动原文件；确认导入时，所选文件会被复制到你指定的目标文档库。应用可能在文档库内的 .argos/library.json 保存相对路径形式的排除记录和手动分类。

移除文档或断开文档库不等于删除原文件，也不保证立即清除所有本地缓存。若文档库位于 iCloud 或其他同步文件夹，原文件及库内配置可能由相应同步服务同步；这受你与该服务的设置和政策约束。

3. 发行渠道与匿名使用统计

为了解每日活跃人数、启动次数、功能使用量、扫描表现和常见错误，独立安装版通过 TelemetryDeck 默认发送匿名使用统计，不显示首次同意流程，也不提供关闭开关。App Store 版不链接或初始化 TelemetryDeck，不发送下列统计。两种版本的本地文档管理功能均不依赖统计服务。

独立安装版可能发送以下信息：

  • 预先定义的操作事件，例如启动、连接文档库、扫描、发现或导入文档、打开、复制、分享、分类和移除。
  • 文档数量、处理耗时和失败数量的区间，以及预先定义的错误类型。
  • SDK 的匿名化安装标识、按小时处理的事件时间，以及系统版本、设备类型、应用版本、构建号和分发渠道等技术信息。

统计不包含 HTML 正文、文件名、文件夹名称、完整文件路径、搜索词或自由输入的错误文本。阿戈斯不提供账户登录，也不使用这些统计进行广告跟踪。

TelemetryDeck 的官方隐私说明称，其服务器不保存 IP 地址；冷数据目前没有承诺的固定删除期限，官方预计可能保留 7 至 10 年但不作保证。有关该服务的数据处理详情，请查阅 TelemetryDeck 隐私政策。

4. 预览、打开与分享

本地封面预览禁用 JavaScript，并阻止 HTTP / HTTPS 远程资源。打开原始 HTML 文档后，关联的浏览器或其他应用可能执行脚本或访问页面引用的在线服务，其行为不受本地封面预览限制。请只打开你信任的内容。

独立安装版使用 Sparkle 从本 GitHub Pages 站点检查更新，默认每日检查，可在设置中关闭；请求可能包含应用版本、构建号和系统版本等技术信息，但不包含文档库内容或 Sparkle 的可选系统画像。App Store 版向 Apple 查询公开版本信息，并由 App Store 负责下载和安装。GitHub、Apple 与网络服务会接收建立连接所需的 IP 地址，并可能按各自政策记录访问日志。

复制或分享由你主动触发，使用系统剪贴板或分享服务。“发送到微信”会复制文件并尝试打开微信，需要你自行粘贴并确认发送。外部应用、网站、云同步和邮件服务的信息处理遵循各自政策。

5. 保留期限与管理方式

  • 原始文档：由你保管和删除，断开连接不会删除文件。
  • 本地索引、缓存与设置：为持续提供功能而保存在设备上。你可以断开文档库、调整系统授权；如需进一步清理应用数据，可联系我们获取帮助。
  • 使用统计：独立安装版默认上报且不提供关闭开关；如不希望发送，请改用 App Store 版。TelemetryDeck 的冷数据目前没有承诺的固定删除期限，官方预计可能保留 7 至 10 年但不作保证。历史事件已匿名化，通常无法根据姓名、邮箱或设备身份定位并单独删除。
  • 账户：应用不设阿戈斯账户，因此没有账户删除流程。

如希望了解、访问、更正或删除你主动提供给我们的信息，请通过下方邮箱联系。我们会根据实际持有的信息、请求的可行性和适用要求处理，不会为了处理请求而要求你发送无关的私人文件。

6. 支持邮件与本网站

你主动发来邮件时，我们会收到你的邮箱地址、邮件内容及附件，用于回复、排查问题和处理相关请求。请只提供必要信息，并先对截图、文档和日志脱敏。支持信息会按处理请求及必要后续沟通的需要保留；你可以联系请求删除。

本网站不添加广告、使用统计脚本、登录功能或自建追踪 Cookie。网站由 GitHub Pages 托管；GitHub 为安全目的会记录访问者 IP 地址。详见 GitHub Pages 说明及 GitHub 隐私声明。

7. 政策更新与联系

当应用功能或数据处理方式变化时，我们会更新本页与生效日期，并按需要在应用内说明重要变更。

开发者与隐私联系邮箱：bobbyye2026@qq.com。使用问题也可先查看支持页。

Privacy policy

Effective September 5, 2026 · Argos standalone and App Store editions for macOS, and this support website

1. Developer and contact

This policy is provided by the Argos developer, GitHub account bobbyye19890223-bit. Contact bobbyye2026@qq.com with privacy questions or requests.

2. Local documents and folder access

After you select or add a library, Argos reads its HTML / HTM documents locally to create titles, summaries, metadata, search indexes, classifications and cover previews. The App Store edition is confined by App Sandbox and stores folder access through system authorization and security-scoped bookmarks. The standalone edition does not enable App Sandbox and therefore does not use the same sandbox authorization flow. By design it scans only libraries you add, but macOS does not technically confine its file access with App Sandbox. Preferences, indexes, caches and related path records remain on your device. Argos does not upload your documents or library to a developer-operated server.

Connecting a library does not copy or move original files. Confirmed imports copy selected files to your chosen destination. Exclusions and manual classifications may be saved using relative paths in .argos/library.json inside a library folder. Removing items or disconnecting a library does not delete the originals or necessarily erase all local caches immediately.

If a library is in iCloud or another synchronized folder, that provider may synchronize files and library settings according to your configuration and its policies.

3. Distribution channels and anonymous analytics

To measure daily active users, launch counts, feature usage, scanning performance and common errors, the standalone edition sends anonymous analytics through TelemetryDeck by default. It has no first-run consent flow and no analytics off switch. The App Store edition neither links nor initializes TelemetryDeck and sends none of the analytics below. Local library features in both editions do not depend on the analytics service.

Standalone analytics may include predefined events such as launches, library connections, scans, discovery, imports and document actions; ranges for counts and processing times; fixed error categories; an anonymized installation identifier; hour-level event times; and technical metadata such as OS, device type, app version, build and distribution channel.

Analytics do not include document contents, filenames, folder names, full paths, search queries or free-form error text. Argos does not offer app accounts or use these analytics for advertising tracking. TelemetryDeck states that it does not store IP addresses. It currently promises no fixed retention period for cold data and estimates that it may be retained for 7 to 10 years without guarantee. See its privacy FAQ and privacy policy.

4. Previews, external apps and sharing

Local cover previews disable JavaScript and remote HTTP / HTTPS resources. Opening the original HTML in an associated application may run scripts or contact online resources; the preview restrictions do not apply there. Only open content you trust.

The standalone edition uses Sparkle to check this GitHub Pages site for updates daily by default; you may disable update checks in Settings. Requests may include the app version, build number and OS version, but not library contents or Sparkle's optional system profile. The App Store edition queries Apple for public version information, and the App Store handles downloads and installation. GitHub, Apple and network providers receive the IP address needed to establish a connection and may log requests under their policies.

Copying and sharing are initiated by you and use the clipboard or system share services. The WeChat option copies a file and attempts to open WeChat; you paste and confirm sending yourself. External browsers, websites, sharing apps, cloud storage and email providers have their own privacy policies.

5. Retention and your choices

You control the original documents. Indexes, caches and settings remain locally to support the app; disconnecting a library does not delete its original files. You may disconnect libraries or adjust system access. Contact us for help with further cleanup.

The standalone edition submits analytics by default and has no off switch; use the App Store edition if you do not want these submissions. TelemetryDeck currently promises no fixed retention period for cold data and estimates 7 to 10 years without guarantee. Historical events are anonymized and generally cannot be located or deleted individually by name, email or device identity. There is no Argos account to delete.

Contact us to ask about access, correction or deletion of information you have voluntarily provided. We will respond based on what we actually hold, what is feasible and applicable requirements, without asking for unrelated private files.

6. Support email and this website

If you email us, we receive your email address, message and attachments to respond, investigate issues and handle requests. Provide only necessary information and redact sensitive content. Support correspondence is kept as needed to address the request and necessary follow-up; you may request deletion.

This site adds no advertising, analytics scripts, login or custom tracking cookies. GitHub Pages hosts it and logs visitor IP addresses for security. See the Pages documentation and GitHub Privacy Statement.

7. Updates

We will update this page and its effective date as features or data practices change, with in-app notice of material changes where needed. Contact: bobbyye2026@qq.com.
